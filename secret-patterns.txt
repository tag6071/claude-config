# Project-specific secret patterns for block-secrets.py.
# One Python regex per line. Blank lines and lines starting with '#' are ignored.
# Patterns are matched case-insensitively against the Bash command text or Read file_path.
#
# Examples (uncomment / customize as needed):
#
#   infra-secrets-yml: \binfra[/_-]secrets?\.ya?ml\b
#   custom-vault-dir: /vault/private/
#   dns-api-key: dns[_-]?api[_-]?key

# --- LIVE patterns ---
# The content sniff in block-secrets.py needs a LOCAL file to open. These cover
# the cases it cannot reach: remote paths (`ssh host "cat .../oidc.yml"`) and
# files that don't exist on this box. Name-matching is the OUTER layer.
#
# A config file held an RSA private key, matched no generic pattern, and a
# `sed -n 1,60p` on it dumped the key into a session transcript.
\boidc\.ya?ml\b
\bvault\.ya?ml\b
\b[\w.-]*\.vault\.ya?ml\b
\bvault[_-]pass(word)?(\.txt)?\b
